# Contributing to WanderWise

Thank you for your interest in contributing to WanderWise! This document provides guidelines and steps for contributing to our project.

## Rules of Contribution

1. Please follow our [Code of Conduct](CODE_OF_CONDUCT.md)
2. Ensure your code follows the existing style and structure
3. Write clear, concise commit messages
4. Document any changes you make
5. Test your changes thoroughly before submitting
6. Create meaningful and specific pull request descriptions
7. Be respectful and constructive in discussions

## Getting Started

### 1. Star the Project ⭐
First, show your support by starring the WanderWise repository! This helps us grow our community.

### 2. Fork the Repository
- Navigate to [WanderWise Repository](https://github.com/Balamurugan-cyber/WanderWise-Smart-routes.-Hidden-gems.-Travel-smarter.-)
- Click the "Fork" button in the top right corner
- This will create a copy of the repository in your GitHub account

### 3. Clone the Repository
```bash
git clone https://github.com/YOUR-USERNAME/WanderWise-Smart-routes.-Hidden-gems.-Travel-smarter.-.git
cd WanderWise-Smart-routes.-Hidden-gems.-Travel-smarter.-
```

### 4. Install Dependencies

For the backend:
```bash
cd backend
npm install
```

For the frontend:
```bash
cd frontend
npm install
```

### 5. API Key Setup
1. Create a `.env` file in the backend directory
2. Add the following environment variables:
```
PORT=3000
OPENROUTER_API_KEY=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
```

### 6. Making Changes
1. Create a new branch for your feature:
```bash
git checkout -b feature/your-feature-name
```

2. Make your changes to the code
3. Test your changes thoroughly
4. Follow the coding style guidelines

### 7. Committing and Pushing Changes
1. Add your changes:
```bash
git add .
```

2. Commit your changes:
```bash
git commit -m "Add: Brief description of your changes"
```

3. Push to your fork:
```bash
git push origin feature/your-feature-name
```

### 8. Creating a Pull Request
1. Go to your fork on GitHub
2. Click "New Pull Request"
3. Select your feature branch
4. Fill in the PR template with:
   - Description of changes
   - Issue number (if applicable)
   - Screenshots (if UI changes)
   - Additional context
5. Submit the pull request

## Happy Contributing! 🎉

Your contributions make WanderWise better for everyone. We appreciate your time and effort in helping us improve this project!
